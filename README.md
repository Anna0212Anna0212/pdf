# PDF 頁面工作台

多個 PDF 之間的頁面可以自由挑選、交叉重組、複製、刪除、旋轉、排序，最後自行決定匯出成一個或多個 PDF。
純前端網頁，**檔案只在你的瀏覽器內處理，不會上傳到任何伺服器**。

https://anna0212anna0212.github.io/pdf/ 
## 功能

**來源（左側）**
- 一次載入多個 PDF（按鈕或直接拖進視窗）；每個檔案用不同顏色標記，輸出頁面會顯示來源檔名與原頁碼
- 縮圖只在捲動到可見範圍時才渲染，幾百、幾千頁也不會卡
- 點頁面選取（Shift 點擊可選連續範圍），或輸入頁碼範圍 `1-5,8,10-12` → 「加入範圍」
- 「整份加入」「全選」「加入選取」；可直接拖曳頁面到右側指定位置

**輸出（右側）**
- 可建立多個輸出，每個輸出就是一份獨立的 PDF；雙擊分頁名稱可改名（即匯出檔名）
- 把頁面拖到另一個輸出的分頁上，即可複製過去；也有「複製過去／移動過去」按鈕
- 拖曳排序（可多選一起拖）、複製、刪除、旋轉、移到最前／最後、左右微調、反轉順序、插入空白頁
- 大量頁面快速操作：全選／反選／奇數頁／偶數頁／輸入頁碼範圍選取
- 縮圖大小滑桿、雙擊頁面放大預覽
- 復原／重做（最多 100 步）

**匯出**
- 勾選要匯出的輸出：各自一個 PDF，或全部合併成一個
- 可「每 N 頁切成一個檔案」（例如 500 頁拆成每 50 頁一份）
- 可只匯出目前已選取的頁面
- 多個檔案可打包成 ZIP，或逐一下載

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| Ctrl/⌘ + Z / Y | 復原 / 重做 |
| Ctrl/⌘ + A | 全選輸出頁面 |
| Ctrl/⌘ + D | 複製選取頁面 |
| Delete / Backspace | 刪除選取頁面 |
| Shift + 點擊 | 選取連續範圍 |

## 部署到 GitHub Pages

1. 建立新的 GitHub repository，把 `index.html`、`README.md` 上傳到根目錄
2. 到 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main` / `/ (root)`，儲存
3. 約一分鐘後即可在 `https://<你的帳號>.github.io/<repo 名稱>/` 使用

> 本專案使用 CDN 載入 [pdf-lib](https://pdf-lib.js.org/)（編輯與匯出）、[pdf.js](https://mozilla.github.io/pdf.js/)（縮圖與預覽）、[JSZip](https://stuk.github.io/jszip/)（打包 ZIP）以及 Google Fonts（字型），使用時需要網路連線。若想完全離線使用，可把這些檔案下載到 repo 內並修改 `<script>` 路徑；pdf.js 的 worker 載入位置在程式碼的 `WURL`。

## 已知限制

- 有密碼保護的 PDF 需先解除密碼才能載入
- 書籤、目錄連結、表單欄位、註解互動等不一定會保留，匯出的是「頁面內容」的重組
- 非常大的檔案（總計數百 MB）受瀏覽器記憶體限制，建議分批處理，或用「每 N 頁切開」匯出
- 重新整理頁面後工作內容會清空（離開前瀏覽器會提醒）
